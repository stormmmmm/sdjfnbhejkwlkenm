# AGENTS.md — нейросетевой синтез ДОЭ

## 1. Суть проекта

Разработать **нейросетевой метод**, который по **четырём заданным изображениям** создаёт **один фазовый дифракционный оптический элемент (ДОЭ)**. При освещении зелёным лазером каждое изображение должно восстанавливаться из **того же ДОЭ** в своей плоскости на заданном расстоянии.

Источник ТЗ: презентация «Разработка нейросетевого метода синтеза дифракционных оптических элементов», слайды 2–6.

## 2. Техническое задание

| Параметр | Требование |
| --- | --- |
| Вход | 4 изображения PNG, по 128×128 пикселей, 8 бит, один канал (grayscale) |
| Метод синтеза | Нейросетевой алгоритм: 4 изображения → **1 ДОЭ** |
| Тип ДОЭ | Фазовый, 128×128 пикселей, значения фазы от −π до +π |
| Файл ДОЭ | PNG, 128×128, 8 бит, один канал; `0` → `−π`, `255` → `+π` |
| Длина волны | 532 нм |
| Размер пикселя ПВМС | 10 мкм |
| Расстояния восстановления | Изображение 1: **24,1 мм**; 2: **25,3 мм**; 3: **26,5 мм**; 4: **27,7 мм** |
| Физическая модель | Прямой расчёт дифракции Френеля **с одним преобразованием Фурье** для каждой плоскости |
| Выходные реконструкции | 4 изображения PNG, по 128×128 пикселей, 8 бит, один канал |
| Метрики | Коэффициент корреляции Пирсона и индекс структурного сходства (SSIM) для каждой из 4 пар «оригинал — реконструкция» |
| Материалы для сдачи | Программный код, данные, файлы результатов и всё необходимое для воспроизведения |

Четыре плоскости восстановления используют **одну и ту же фазовую карту**; запрещено подменять задачу четырьмя независимыми ДОЭ. Реконструкции должны получаться **численным распространением оптического поля**, а не произвольной обработкой изображений.

Для фазовой маски используйте комплексное поле `H(u,v) = A(u,v) · exp(i·φ(u,v))`, где `φ ∈ [−π, π]`. Для каждой дистанции `z` рассчитайте поле `K_z` методом Френеля с одним 2D FFT и интенсивность `I_z = |K_z|²`. Соблюдайте физические единицы, дискретизацию и масштаб координат выходной плоскости (для одно-FFT метода он зависит от `z`). Профиль падающего поля `A`, нормировку интенсивности и иные неуказанные параметры следует явно описать как допущения.

Фазу кодируйте в PNG по фиксированной шкале `uint8 = round(255 · (φ + π)/(2π))` с ограничением в `[0,255]`. Для финальных реконструкций и метрик **загрузите сохранённый файл ДОЭ, декодируйте фазу обратно** и выполните расчёт Френеля: так учитывается 8-битное квантование.

## 3. Правила работы агента

1. Перед изменениями изучай существующий проект и исходное ТЗ. Сохраняй рабочий код и пользовательские данные.
2. Строго соблюдай размеры, форматы, физические параметры и соответствие изображений расстояниям. Не изменяй их без явного разрешения.
3. Реализуй **именно нейросетевой** синтез. Классические итеративные методы могут быть вспомогательными, но не заменять нейросеть.
4. Отделяй требования ТЗ от собственных допущений и решений (архитектура, обучение, функция потерь, нормировка, модель освещения). Не заявляй неподтверждённых преимуществ по скорости или качеству.
5. Используй согласованную физическую модель при обучении, восстановлении и оценке. Не подменяй оптическую реконструкцию нейросетевой визуализацией.
6. Проверяй код тестами: формы и типы данных, диапазон и PNG-кодировку фазы, корректность распространения, конечность значений, прохождение градиентов при обучении и сквозной запуск.
7. Считай Pearson и SSIM **отдельно для каждого из четырёх восстановлений**; указывай правила нормировки. Не придумывай показатели и не объявляй непроверенные тесты пройденными.
8. Обеспечь воспроизводимость запуска: зафиксируй зависимости, параметры, случайный seed, способ обучения/загрузки модели и команды запуска.
9. Если реальные входные изображения не предоставлены, разрешены явно помеченные тестовые примеры, но нельзя выдавать их за исходные данные кейса или объявлять итоговую задачу выполненной.
10. После изменений кратко сообщай, что сделано, что протестировано и какие ограничения остались.
11. Не забывай спрашивать вопросы, если видишь несостыковки или неочевидные места. Задавай вопрос всегда, если видишь несогласованность или хочешь внести изменения в архитектуру. Всегда задавай вопросы про архитектуру.
